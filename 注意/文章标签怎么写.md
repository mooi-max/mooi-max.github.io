每篇文章顶部加 `tags` 就行，比如：


```
---
title: Nmap常用命令
description: 记录 Nmap 在 CTF 和靶机测试中的常用扫描命令
date: 2026-04-29
tags:
  - CTF
  - Nmap
  - 信息收集
---

# Nmap常用命令
```

## 推荐每个文件夹都建一个 `index`

比如你新建：

```
content/工具开发/
```

然后在这个文件夹里新建一篇笔记，名字只写：

```
index
```

不要写 `index.md`，因为 Obsidian 会自动加 `.md`。

内容可以这样写：

```
---title: 工具开发description: 记录脚本、小工具、自动化程序和项目开发过程tags:  - 工具开发---# 工具开发这里记录我写的小工具、脚本、自动化程序和项目开发过程。## 文章列表- [[Python脚本开发]]- [[渗透测试小工具]]
```

这样访问目录页时会更清楚。
