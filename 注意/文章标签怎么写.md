每篇文章顶部加 `tags` 就行，比如：


```
---
title: Nmap常用命令
description: 记录 Nmap 在 CTF 和靶机测试中的常用扫描命令
date: 2026-04-29
tags:
  - CTF
  - Nmap
  - 信息收集
---

# Nmap常用命令
```

## 推荐每个文件夹都建一个 `index`

比如你新建：

```
content/工具开发/
```

然后在这个文件夹里新建一篇笔记，名字只写：

```
index
```

不要写 `index.md`，因为 Obsidian 会自动加 `.md`。

内容可以这样写：

```
---
title: Nmap 常用扫描命令整理
description: 整理 Nmap 在 CTF、靶机测试和内网信息收集中的常用扫描命令，包括端口扫描、服务识别、脚本扫描和 UDP 扫描。
tags:
  - CTF
  - Nmap
  - 信息收集
---
```

这样访问目录页时会更清楚。
