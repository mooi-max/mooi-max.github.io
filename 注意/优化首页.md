# 一、最优先：优化首页

首页现在不要只是普通目录，最好让别人一进来就知道：

```
这个博客是谁写的
主要写什么内容
哪些文章值得先看
怎么快速找到内容
```

首页可以改成这种结构：

```
# Mooi 的个人技术笔记

这里记录我的 CTF、Linux、Docker、数据库、工具教程和学习复盘。

## 主要内容

- [[CTF/index|CTF 笔记]]
- [[Linux/index|Linux 笔记]]
- [[数据库/index|数据库]]
- [[Docker/index|Docker]]
- [[工具教程/index|工具教程]]
- [[随笔/index|随笔]]

## 推荐阅读

- [[CTF/Nmap常用命令|Nmap 常用命令]]
- [[Linux/Linux常用命令|Linux 常用命令]]
- [[Docker/Docker部署记录|Docker 部署记录]]

## 最近在整理

- Web 安全基础
- 靶机复盘
- Linux 提权笔记
- Docker 部署教程
```

首页是门面，这个优先级最高。
